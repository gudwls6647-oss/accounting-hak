## §1. 사용자 4단 계층 + 외부/내부 차원

### §1.1. 4단 계층

원가관리는 단일 사용자가 아니라 회사 안의 **4단 계층** 사용자들이 협업하는 구조.

```
[1단] 현장 — 회계담당자/원가팀, 생산관리자
  도구: 1~4장 직접·간접원가, 보조부문 배분, 개별/종합/결합 원가,
       8장 표준원가 적용

[2단] 기획 — 사업기획팀
  도구: 5장 일부, 6장 CVP, 7장 단기 의사결정 분석

[3단] 재무 — CFO/예산팀
  도구: 5장 일부, 8장 종합예산, 8장 차이분석, 
       9장 판매부문 평가, 10장 사내대체

[4단] 경영진 — CEO/사장단
  도구: 11장 전략 (JIT, TQC, TOC, BSC 등)
  특징: 1~10장이 "기존 시스템 안 최적화"라면
       11장은 "시스템 자체를 교체"하는 결정
       1~10장 = 방법 / 11장 = 철학
       5~10년 영향, 전사적 동원 필요
```

= **위로 갈수록 추상화.** 1단은 "이 제품 얼마", 4단은 "회사 어디로?"

### §1.2. 협업 단 (정수 단 사이)

```
1.5단 = 1단 ↔ 2단 협업 (현장 ↔ 기획)
2.5단 = 2단 ↔ 3단 협업 (기획 ↔ 재무)
3.5단 = 3단 ↔ 4단 협업 (재무 ↔ 경영진)
```

협업 단 = **재프레임 단 = 데이터 변환 단.** §2에서 자세히.

### §1.3. 7장/9장 = 도구함 (단별로 갈라짐)

같은 챕터 안에 여러 단의 도구가 묶여있음:

```
7장:
  단기 의사결정 (특별주문/외주/라인폐쇄) = 2.5단
  장기 의사결정 (자본예산/NPV) = 3.5~4단

9장:
  판매부문 평가 (매출차이분석) = 3단
  투자중심점 평가 (ROI/RI/EVA) = 3.5단
```

= **"챕터 = 도구함" 인식 필요.** 한 챕터 안에서도 도구 성격이 갈림.

### §1.4. 시간축 = 사용자 단 결정

```
단기 (1년 이내) → 2~3단
장기 (5년~) → 3.5~4단
초장기 → 4단
```

= **시간축이 길어질수록 사용자 단 위로.** 단기는 한 단에서 끝나도 되지만, 장기는 정보가 위로 올라가야 결정 가능.

3.5단 도구들이 모두 "장기"인 게 우연 아님:
- NPV/자본예산 = 5~10년
- ROI/RI/EVA = 누적 성과
- 11장 전략 = 초장기

### §1.5. 외부 강제 vs 내부 자유 차원

4단 계층과 직교하는 또 하나의 차원이 있음 — **결과물이 외부 보고용인가 내부 의사결정용인가.**

**[외부 강제 영역]**

```
무엇이 강제되나:
  - 제조원가명세서 양식 (항목 구조)
  - 비용계정 분류 (재료비/노무비/경비)
  - 발생주의 (시점)
  - 전부원가계산 (원가 범위)
  - 실제 전부원가 (기말 환산 후)
  - 정상공손/비정상공손 구분 (비정상은 8.타계정 대체로 빠짐)
  - 재고자산/매출원가 (재무제표 결과)

왜 강제:
  사용자 = 투자자
  투자자 신뢰 기준 = 회계 표준 (회사 비교 가능성)
  → 양식 통일 + 보수적 시점 + 실제만 인정
```

**[내부 자유 영역]**

```
무엇이 자유:
  - 보조부문 배분법 (직접/단계/상호)
  - 단일/이중 배분율
  - 전통 배분 vs ABC
  - 실제원가 / 정상원가 / 표준원가
  - 변동원가계산 활용
  - 사내대체가격 결정
  - CVP, 단기 의사결정
  - 자본예산 / NPV

왜 자유:
  사용자 = 경영자
  경영자 신뢰 기준 = 의사결정 유용성
  → 회사 특성에 맞게 도구 선택
```

**[회사 자동 결정 영역]**

```
개별/종합/결합원가 = 회사 생산 방식에 따라 자연 결정
  조선소 = 개별 / 시멘트 = 종합 / 정유소 = 결합
  → 선택이 아니라 매칭
```

### §1.6. 두 차원의 결합

**4단 계층과 외부/내부 차원의 매핑:**

```
1단~1.5단:
  외부 강제 결과물 만드는 영역
  (제조원가명세서, 재고자산, 매출원가)
  
1.5단 = 두 영역 사이 변환 단 (가장 중요)
  "외부 보고용 데이터" ↔ "내부 의사결정용 데이터"
  
2단~4단:
  내부 자유 의사결정 영역
  (CVP, 단기/장기 결정, 평가, 전략)
```

**같은 도구를 두 용도로 사용:**

```
ABC, 보조부문 배분, 이중배분율, 정상원가:
  외부용: 제품원가 계산 → 재고/매출원가 → 재무제표
  내부용: 활동/부서/시점 분석 → 의사결정
  
= 같은 데이터, 두 용도
= 1.5단이 그 변환을 담당
```

**외부 보고 시점 = 실제 전부원가 환산 필수:**

```
평소(내부):
  - 정상원가로 빠르게 처리
  - ABC로 활동별 분석
  - 변동원가계산으로 의사결정
  - 표준원가로 성과평가

기말(외부):
  - 배부차이 조정 → 실제 전부원가화
  - 변동원가 → 전부원가 환산
  - 표준 차이 → 매출원가/재고 배분
  
= 평소 자유, 기말 환산
```

### §1.7. 1장 좌표 시스템

**1장이 모든 도구의 기준점.**

```
1장 = 원가의 분류 + 원가의 흐름
    = 모든 도구의 좌표 시스템
    
왜 1장이 1장인가:
  - 모든 도구가 1장 기준 위에서 작동
  - 정상/표준원가 차이조정 = 실제 발생 총액(1장) 기준
  - ABC/배분법 결과 = 1장 발생액을 어떻게 나눌지
  - 손익계산서 매출원가 = 1장 흐름의 끝
```

**1장의 좌표 차원들:**

```
1장 원가 분류:
  발생형태별 (재료비/노무비/경비)
    → 제조원가명세서 항목
  추적 가능성 (직접/간접)
    → ABC/배분법의 대상
  원가행태 (변동/고정)
    → CVP, 이중배분율, 변동원가계산
  관련성 (관련/매몰/기회)
    → 7장 의사결정
  제품/기간 (제품원가/기간비용)
    → 외부 강제 vs 자유 구분

1장 원가 흐름:
  발생 → 재공품 → 제품 → 매출원가
  = 자산 → 비용 변환의 시간축
  = 모든 도구가 이 흐름 위에서 작동
```

**4차원으로 정리 (5/8 발견):**

```
차원 A (무대): 개별/종합/결합 → 1장의 "제품원가 흐름 방식"
차원 B (간접원가): 전통/ABC → 1장의 "직접/간접" 분류
차원 C (원가범위): 전부/변동/초변동 → 1장의 "원가행태" 분류
차원 D (측정시점): 실제/정상/표준 → 1장의 "원가 흐름 시점"

외부 강제 차원:
  C = 전부원가 강제
  D = 실제원가 강제 (조정 후)
  A, B = 회사 선택 가능
```

= **1장 없이는 2장 이후가 작동 안 함.** 1장이 좌표 시스템 자체.
= **2장 이후 = 1장 좌표 위의 도구들.**

## §2. 협업 단 — 진짜 발견

### §2.1. 협업 단 = 재프레임 단 = 데이터 변환 단

```
모든 협업 단 (1.5/2.5/3.5) 도구의 공통점:
  같은 데이터를 다른 관점으로 변환
  = 재프레임
  = 본질적으로 협업 (두 사용자 사이)
```

**협업 단 데이터 변환 일반 패턴:**

```
1.5단: 회계 데이터 → 원인 데이터 (얼마 → 왜?)
2.5단: 원인 데이터 → 미래 시나리오 (왜 → 이렇게 하면 어떨까?)
3.5단: 시나리오 결과 → 전략 결정 (그래서 → 회사 어디로?)

= 각 단이 데이터 추상도를 한 단계씩 올림
```

### §2.2. 1.5단 도구 = "기록"을 "의미"로 변환

**ABC: "원가 발생 원인" 데이터로 전환**

```
Before: "제조부서 원가 1억" (총액, 결과)
After:  "주문접수활동 200만, 검사활동 300만, 작업준비활동 400만..." (원인)

목적: 기획팀이 "어느 활동 줄이면 원가 줄어드나" 의사결정 가능
```

**상호배분법: "부서 간 의존 관계" 데이터로 전환**

```
Before: "수선부 → 제조부서로만 일방향 흐름"
After:  "수선부 ↔ 동력부 상호 + 양쪽 다 제조부서에"

목적: 진짜 부서별 원가 비중 가시화 → 부서장 평가 정확도 ↑
```

**이중배분율법: "원가의 발생 동기" 데이터로 전환**

```
Before: "수선부 원가 644,000을 시간 기준 배분" (한 덩어리)
After:  "변동(실제 시간) + 고정(최대 시간 기준) 분리" (메커니즘)

목적: 통제 가능한 변동 vs 통제 불가능한 고정 분리
     → 평가 공정성 + 의사결정 정확도

특수 의미: 한국 노동 정책(포괄→비포괄 임금제)과 isomorphic 구조
  - 기본급 = 약속한 수용력 (고정원가)
  - 추가급 = 실제 추가 사용 (변동원가)
  = 회계학 1940년대 도구가 한국 노동 정책과 같은 구조
```

**노무비 T-계정 = 1.5단의 가장 기초 변환 (5/11 발견):**

```
        노무비 (사용액 계산표)
  ┌─────────────┬─────────────┐
  │ 차변          │ 대변         │
  │ (현금주의)    │ (발생주의)   │
  │              │              │
  │ 미지급        │             │
  │ 당기지급      │ 사용액       │
  │ 선급         │             │
  └─────────────┴─────────────┘
       현금 흐름          발생주의 비용

= T-계정 자체가 "현금주의 → 발생주의 변환기"
= 1.5단 변환의 가장 작은 단위
= 회계 전체 원리의 축소판

회계 전체로 일반화:
  - 매출채권 = 매출(발생) vs 현금(수령) 차이
  - 매입채무 = 매입(발생) vs 현금(지급) 차이
  - 감가상각 = 자산 → 비용 시간 변환
  - 충당금 = 미래 비용 미리 인식
  - 외화환산 = 평가 시점
  - 경과계정 = 기말 시점 보정
  
= 회계 = 현금 시점과 사용/실현 시점의 차이 보정 시스템
```

### §2.3. 시간 통제 = 원가관리의 핵심

**11챕터 전체가 시간으로 환원 가능:**

```
1장 원가 분류: 원가행태 = 시간 비례(변동) / 시간 무관(고정)
1장 원가 흐름: 자산 → 비용의 시간축
1장 ABC: 활동별 시간으로 원가 재분배
2장 개별원가: 작업별 시간 추적
3장 종합원가: 공정 흐름 시간 (완성도 = 시간 진행도)
4장 결합원가: 분리점 = 시간상 어디서 갈라지나
5장 변동/고정: 변동 = 시간 비례 / 고정 = 시간 무관
6장 CVP: 영업레버리지 = 고정시간 비중
7장 단기의사결정: 매몰원가 = 과거 시간 / 관련원가 = 미래 시간
8장 표준원가: 표준 = 표준 시간 / 능률차이 = 시간 차이
9장 평가: ROI = 투자 시간 회수율
10장 사내대체: 기회비용 = 다른 데 쓸 수 있던 시간
11장 JIT/TOC: 리드타임/사이클타임 = 시간 자체가 주제
```

= **11챕터 전부 시간으로 환원 가능.**

**왜 시간이 핵심인지:**

```
원가 = 자원의 희생
자원 = 사람, 기계, 재료, 자본
  ↓
사람 = 시간 (노동시간)
기계 = 시간 (가동시간)
재료 = 시간 (보유시간, 회전율)
자본 = 시간 (NPV의 t, 회수기간)

= 모든 자원이 결국 "시간 단위"로 환산됨
= 원가 = 시간 × 단가
= 단가는 시장이 정하고, 시간은 회사가 통제
= 회사 통제 가능한 변수 = 시간
```

**원가관리 한 줄 정의:**

```
원가관리 = 원가/시간 통제를 통한 효율화

원가 파트 (1~4장) = 원가 기준 = "얼마 들었나"
관리 파트 (5~11장) = 공헌이익 기준 = "얼마 벌 수 있나"
                     + 외부 강제 영역에서는 전부원가 환산
```

### §2.4. 7장 = 1~6장의 수렴점 ("비관련원가 찾기 게임")

```
1~4장: 원가가 어디로 가는지 추적 (얼마인가)
5장:   원가를 변동/고정으로 재분류 (어떤 성질인가)
6장:   변동/고정으로 BEP 계산 (얼마 팔아야)
7장:   관련/비관련 분리해서 결정 (뭐가 의사결정에 필요한가)
```

**점점 "버릴 것"을 정교하게 골라내는 흐름:**

```
5장: 고정원가는 의사결정에 자주 비관련 (1차 거름)
6장: BEP 분석할 때 변동만 단위 분석 (2차 거름)
7장: 매몰원가/회피불가 고정원가 = 비관련 (최종 거름)
   + 기회비용 = 관련원가에 추가
```

= **7장 = 원가관리 1~6장의 수렴점.**
1~6장이 다 "관련원가 찾기 위한 정보 정제 작업"이고, 7장에서 그 정제된 정보로 실제 결정.

**7장의 두 렌즈:**

```
원가 렌즈:    "이 결정에 필요한 원가만" (관련원가)
공헌이익 렌즈: "이 결정으로 얻는 이익" (관련수익 - 관련원가)

같은 정보를 두 방향으로 봄:
  비용 절감 결정 = 원가 렌즈 (특별주문 거절, 외주, 라인 폐쇄)
  이익 극대화 결정 = 공헌이익 렌즈 (특별주문 수락, 신제품)

제약자원 문제 (단위당 공헌이익/제약자원 단위):
  = 두 렌즈 합쳐짐
  = "제약된 자원을 어디 쓰면 공헌이익 최대?"
```

### §2.5. 8~10장 = 7장 결정의 사후 통제

```
1~4장: 원가 측정 (얼마)
5~6장: 의사결정용으로 재가공 (성질)
7장:    실제 결정 (관련/비관련)
8~10장: 결정 후 통제·평가 (책임 추적)
11장:   전략 (장기 방향)
```

**8~10장 = 전 부서 책임 추적 시스템:**

```
원재료 구매 → 직접재료비 차이 (구매부서)
       ↓
생산 → 직접노무비 차이 (생산부서)
       ↓
       제조간접비 차이 (생산관리)
       ↓
판매 → 매출 차이 (판매부서)

+ 10장 사내대체 = 부서 간 자원 흐름 통제
+ 9장 투자중심점 = 사업부 단위 평가 (3.5단)
```

= **8~10장 = 회사를 부서/사업부 단위로 쪼개서 책임 추적 + 자원 흐름 통제 시스템.**

## §3. 검증 사례

### §3.1. 사례 1: 2024년 세무사 (문제 1) — 이중배분율법

**문제 구조:**
- 물음 1-(1)(2): 보조부문원가 배분, 단위당 제조원가 = **1.5단** (계산)
- 물음 1-(3): 외부수선용역 ₩12 제안 수락 결정 = **3.5단** (점프)
- 물음 2-(2): 특별주문 최소판매가격 = **2.5단** (기회비용 포함)

**3.5단 답:**
- 부문장 입장 (P1): -32,000 (P1 원가 감소, 받아들이는 게 유리)
- 회사 전체 입장: +64,000 (회사 손실)

= **준최적화.** 부문장 평가 기준(배부받은 원가)이 회사 전체와 어긋남.

### §3.2. 사례 2: 2018년 회계사 (문제 2) — ABC

**문제 구조:**
- 물음 1: ABC 영업이익 계산 = **1.5단** (재프레임)
- 물음 2: 목표원가 산정 = **2.5단** (가격 결정)
- 물음 3-(2): 아이스크림 유지/중단 결정 = **3.5단**

**3.5단 함정:**
- 지배인 입장 (영업이익 평가): 아이스크림 (-)212,500 → "끊자"
- 회사 전체 입장: 유지가 +350,000 이득

해설 명시:
> "아이스크림 제품의 영업이익이 (-)212,500이기 때문에 아이스크림 제품의 생산을 중단한다는 결론을 내려서는 안 된다. 의사결정의 기본은 회사전체의 영업이익으로 판단하는 것이다."

### §3.3. 두 사례의 공통 패턴

```
한 문제 안에서:
  앞 물음 = 1.5단 (계산)
  뒷 물음 = 3.5단 (준최적화 함정)

= 시험이 가장 어렵게 묻는 부분 = 3.5단 = 사용자 충돌 식별
```

### §3.4. 시험 풀이 anchor (4질문)

```
Q1. 이 물음의 사용자 누구?
    공장장/기획팀/CFO/사장/부문장/회사 전체 中 무엇?

Q2. 한 문제 안에서 사용자 계층 점프 있나?
    물음 (1)은 1.5단(계산)인데 (3)이 3.5단(결정)으로 점프?
    
Q3. 준최적화 충돌 있나?
    부문장 입장 vs 회사 전체 입장 어긋남 = 시험 함정의 핵심
    
Q4. 협업 단(1.5/2.5/3.5) 도구인가?
    = 정답 없음, 상황 판단 필요
```

**일반 원칙: 사용자 입장 충돌 시 "회사 전체 입장이 정답."**

### §3.5. 재조정 필요 메모

⚠️ **검증은 됐지만 정확도 향상 위해 재해석 필요.**

5/11 발견 적용 시 사례 1·2를 다시 보면:

```

  (어느 좌표 차원의 도구가 사용되는지)

  (외부용 결과 만드는 단계 vs 내부 의사결정 단계 분리)
  
- 시간 통제 관점에서 재해석
  (어느 시간 차원의 의사결정인지)

```
