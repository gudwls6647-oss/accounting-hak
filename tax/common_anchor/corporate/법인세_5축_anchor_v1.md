## §2. 5축 가설 (v1) — 챕터 기반 분류

전산세무1급 이론책 챕터가 그대로 5축으로 묶임:

```
챕터                          축                    실기 세무조정
───────────────────────────────────────────────────────────────
03 익금                      ④ 익금형              임대보증금/수입배당금/작업진행률
04 손금                      ⑤ 손금형              세금과공과
05 손금규제 (접대비/기부금/지급이자) ① 한도형 + ③ 부당행위형
06 감가상각                  ① 한도형              감가상각 시부인
07 인건비/충당금/대손        ① 한도형              퇴직급여/퇴직연금/대손충당금
08 손익귀속/평가             ② 시점형              선급비용/재고/외화
09 부당행위                  ③ 부당행위형          가지급금 인정이자
```

### 5축 작동 메커니즘

```
① 한도형     = 기준액 × 비율
② 시점형     = 시점 강제 매칭 (회계 vs 권리의무 확정)
③ 부당행위형 = 시가 - 거래가 = 차액 인식
④ 익금형     = 열거 + 간주 산식
⑤ 손금형     = 열거 (포함/제외 판정)

= 5축 = 5가지 다른 무기
= 공통점 = "객관성 확보"
```

## §3. 5축 → 3축 압축 (v2 — 형진 발견)

5축을 메커니즘 본질로 묶으면 3축:

```
[메인 축 — 가산조정 = 세금 늘리기]
  A. 한도 초과 손금불산입 (옛 ①)
     A1. Stock base / 추정거부 → 유보
     A2. Flow base / 사용제한 → 기타사외 (제재)
  B. 시점 어긋남 (옛 ②) → 유보/△유보
  C. 부당행위 (옛 ③) → 사외유출
  D. 강제 인식 (간주/의제)
     D1. 회피 방지 (간주임대료) → 기타사외
     D2. 실질 재분류 (의제배당) → 유보

[혜택 축 — 차감조정 = 세금 줄이기]
  E. 익금불산입 (이중과세 방지, 자본거래, 정책)
  F. 손금산입 (전기 부인액 추인 등)

[보조 축 — 0단계 분류 게이트]
  G. 손금/익금 인정 판정 (옛 ⑤)
     → 인정 X면 손금불산입 직행
     → 인정 O면 메인 축으로
```

## §4. 한도형 sub 분류 (형진 발견)

한도형 안에 두 가지 결:

### A1. 시점조정형 (유보 처분)
```
대상: 충당금, 감가상각, 외화평가
처분: 유보
특징:
  - 자산·부채 차이 발생
  - 자본금적립금조정명세서(을)에 누적
  - 차기 이후 반대 조정으로 추인
  - = 일시적 차이

원리: 추정 거부 (회계 추정 한도 제한)
```

### A2. 제재형 (기타사외유출 처분)
```
대상: 접대비, 기부금, 업무용승용차, 업무무관 지급이자
처분: 기타사외
특징:
  - 자산·부채 차이 없음 (이미 비용으로 나간 돈)
  - 추인 X
  - = 영구적 차이

원리: 사용 제한 (한도 넘게 쓴 건 영구적으로 안 인정)
```

## §5. 한도 base = Stock vs Flow (형진 발견)

한도 base가 재무제표 어디에서 오는지에 따라 갈림:

### Stock base (재무상태표 잔액)
```
대손충당금:    채권 잔액 × Max[1%, 대손실적률]
감가상각:      취득가액 × 상각률
→ 한 시점 잔액 = "지금 보유한 것"
→ 자산 자체에 대한 추정 제한
→ 유보 처분 메인
```

### Flow base (손익계산서 누적)
```
충당금형 (미래 비용 추정):
  퇴직급여충당금 = 총급여 × 5% (Min)
  → 유보 처분

사용제한형 (당기 사용 제한):
  접대비 = 수입금액 × 비율 (계층)
  기부금 = 기준소득금액 × 50%(특례) / 10%(일반)
  업무용승용차 = 800만원 한도
  → 기타사외 처분 (제재)
```

## §6. 형태 vs 취지 갈라짐

챕터 위치(형태)와 메커니즘 본질(취지)이 다른 케이스:

```
업무용승용차:
  형태: 04 손금 안 (한도형)
  취지: 부당행위 차단 (개인 사적 사용 막기)

채권자불분명 사채이자:
  형태: 05 지급이자 (한도형 옆자리)
  취지: 부당행위 (귀속자 불명 = 빼돌리기 의심)

업무무관 지급이자:
  형태: 05 지급이자
  취지: 부당행위 (업무 무관 자산 보유 + 차입)

의제배당:
  형태: 03 익금
  취지: 실질 재분류 (D2 — 제재 아님)

간주임대료:
  형태: 03 익금
  취지: 회피 방지 (D1 — 제재성)
```

= **챕터 = 형태, 메커니즘 = 취지.** 5축 매핑 시 둘 다 봐야 함.

## §7. 세무조정 공통 골격

5축으로 차이 발견 → 공통 골격으로 처분:

```
[1] 회사 장부 vs 세법 기준 비교
    → 차이 발견 (5축 중 어느 축 메커니즘으로)

[2] 4방향 중 어느 조정?
    수익 < 익금 → 익금산입 (↑)
    수익 > 익금 → 익금불산입 (↓)
    비용 < 손금 → 손금산입 (↓)
    비용 > 손금 → 손금불산입 (↑)

[3] 가산/차감 압축
    가산조정 (소득 ↑) 또는 차감조정 (소득 ↓)

[4] 가산이면 → 사외유출 O/X?
    O면 귀속자 확인:
      주주 → 배당 (원천징수 O)
      임직원 → 상여 (원천징수 O)
      법인/사업자/국가 → 기타사외 (원천징수 X)
      그 외 개인 → 기타소득 (원천징수 O)
    X면 자산·부채 차이 O/X?
      O → 유보 (사후관리)
      X → 기타 (끝)

[5] 서식 기재
    소득금액조정합계표 (기부금 한도초과 제외)
    유보면 자본금적립금조정명세서(을)에 누적

= 5축은 [1]에서만 결정
= [2]~[5]는 공통
```

## §8. 소득처분 = 관계 기반 + 추적 비용 최소화

```
귀속자                추적 방식                원천징수
────────────────────────────────────────────────────────
주주(개인)            법인 → 즉시 잡기         O (배당소득)
임직원(개인)          법인 → 즉시 잡기         O (근로소득)
기타개인(친족 등)     법인 → 즉시 잡기         O (기타소득)
법인/사업자/국가      각자 신고로 잡힘          X (기타사외)

= 개인 = 추적 어려움 → 회사가 대신 (원천징수)
= 법인/사업자 = 추적 시스템 있음 → 자력
= 국가 = 이미 안에 있음

처분 분류 = 관계 카테고리:
  배당 (출자관계) - 정기
  상여 (근로관계) - 정기
  기타소득 (그 외 개인) - 일회성
  기타사외 (사업/법인) - 이미 추적됨

= 소득세법 4 카테고리와 직접 매핑
= 처분 = 받는 사람의 소득세법상 소득 종류 결정
```

## §9. 결산조정 vs 신고조정 (형진 발견)

```
결산조정 (회사 안 잡으면 국가도 모름):
  - 감가상각비 (내부 추정)
  - 충당금 (내부 추정)
  - 임의 대손사유
  - 평가손실
  = 외부 거래 흔적 X
  = 회사 의사가 출발점
  = 안 잡으면 차기로 밀림

신고조정 (과세관청이 외부 흔적으로 추적):
  - 매출 누락 → 거래 상대방 매입 자료
  - 인건비 → 원천징수 자료
  - 강제 대손사유 → 법원 판결문
  - 퇴직연금 → 외부 금융기관 입금
  - 업무용승용차 → 차량등록/구매 영수증
  - 채권자불분명 사채이자 → 원천징수 자료 없음 = 흔적
  = 외부 데이터 흐름 있음
  = 회사 안 잡아도 강제

= 결산조정 = ① 한도형 A1(추정거부) 영역 메인
= 나머지 축 = 대부분 신고조정
```

## §10. 비망가액 1,000원 (형진 발견)

```
비망가액 = "비용은 인정, 자산/권리 살아있음" 표식

3 케이스:
  ① 정률법 감가상각 종료 자산: 자산 형체 존재 + 비용 잡음 완료
  ② 결산조정 대손 채권: 권리 살아있음 + 비용 잡음
  ③ 자체 판단 파산/부도 주식: 권리 살아있음 + 평가손 잡음

대비 (비망가액 X):
  - 강제 대손 (소멸시효/법원 면책) = 권리 소멸
  - 파손/멸실 = 형체 소멸
  - 매각/처분 = 형체 소멸 (대신 처분손익으로 정산)

= 형체/권리 살아있음 + 회수/처분 가능성 = 깃발 유지
= 둘 다 소멸 = 깃발 제거

추적 목적:
  - 자산 존재 사실 추적 (장부 0원 = 자산 없음으로 보임 방지)
  - 처분/매각 시점 인식
  - 우발적 회복 시 정상 인식
```

## §11. 추적 장치로서의 세법 (형진 핵심 발견)

### 형진 명제

> 세법의 작은 규정 하나하나가 자산/권리 추적을 위한 장치

### 규정 단위 추적 임무 예시

```
비망가액 1,000원       → 자산 형체/권리 추적
대손 제외 (저당권)     → 회수 가능성 추적
자산계상 기업업무추진비 → 자산에 숨은 비용 추적
폐지/철거 기록         → 자산 행방 추적
결산조정/신고조정 구분 → 외부 흔적 유무 추적
소득처분 귀속자 분류   → 돈 받은 사람 추적
유보 누적 (을)         → 일시적 차이 추적
사외유출 처분          → 회사 밖 귀속자 추적
지급의제 (원천징수)    → 회피 차단 안전망

= 모든 작은 규정 = 각자 다른 추적 임무
```

### 지급의제 = 추적 안전망

```
원래 흐름: 법인 → 원천징수 → 개인 받음
회피 시도: 법인이 안 줬으니까 원천징수 안 함

지급의제:
  법인이 원천징수 미룸 → 법인이 의제 시점에 강제 부담
  = 추적 끊기면 법인이 부담
  = 회피 차단 안전망
```

= 국가가 신뢰할 수 있는 이유 = 이미 다 끝난 데이터

KcLep 법인조정 work order = 데이터 의존성 순서:

  → 최저한세 → 가산세/원천 → 법인세 과세표준세액조정

= 앞 단계 확정 → 뒤 단계 기준액으로 사용
= 기부금이 과목별 마지막인 이유 (기준소득금액 확정 필요)
```

## §13. 평가 비대칭 (형진 발견)

```

  이유: 회사 추정으로 비용 부풀림 차단

  평가증 예외: 법률 강제 (보험업법 등), 외화환산

  평가손 예외: 파산, 천재지변, 재고 파손
    → 객관 사건 발생

= 회사 부담 큰 평가손은 예외 폭 넓음 (실질 반영)
