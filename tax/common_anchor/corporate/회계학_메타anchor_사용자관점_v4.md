## §1. 한 줄 anchor (v4 갱신)

> **회계학 = 영역마다 메인 사용자가 다른 데이터 변환 시스템.**
> **세법 영역 전체는 추적 장치들의 집합이다.**

```
재무회계 = 투자자용 변환 시스템
세법     = 국가용 변환 시스템 + 추적 인프라
원가관리 = 경영자용 변환 시스템 (4단 계층 내부)

각 영역 = 데이터 변환 + 추적 메커니즘
```

────────────────────────────────────────────────────────────

세법(법인세)  국가               객관 증거          권리의무 확정

원가관리      경영자 (4단 계층)  의사결정 유용성    이중 시점
```

## §3. 5단 통합 파이프라인 (v3 유지)

```
[1단]   거래 발생 → 현장 분개
[1.5단] 분류 변환 (노무비 T-계정 = 가장 기초)
[2단]   손익계산서
[2.5단] 결산 변환
[3단]   재무상태표
[3.5단] 현금흐름표 변환
[4단]   외부 공시 (재무회계 끝)
  ↓
[4.5단] 세무조정 (회계 → 세법 변환) ← 법인세 핵심 영역
  ↓
[5단]   세법 신고서 (국가 사용자)
```

법인세 = **4.5단 + 5단 구간**의 변환 작업.

## §4. 법인세 영역 통합 (v4 신규)

### §4.1. 법인세 = 회계 결과물 덧씌우기

```
출발점: 회사가 재무제표 작성 완료 (당기순이익 확정)
작업:   당기순이익에 세법 시각 덧씌우기
도착점: 각 사업연도 소득금액 → 신고서

= 처음부터 만드는 작업이 아님
= 회계 결과물을 변환
```

### §4.2. 법인세 5축 (메커니즘)

```
① 한도형     = 기준액 × 비율 (재무제표 베이스)
  A1 추정거부 → 유보 (Stock/Flow + 충당금)
  A2 제재    → 기타사외 (Flow + 사용제한)

② 시점형     = 회계 시점 vs 권리의무 확정주의 충돌
③ 부당행위형 = 시가 - 거래가 = 차액 인식 (사외유출)
④ 익금형     = 열거 + 간주 산식
  D1 회피 방지 (간주임대료)
  D2 실질 재분류 (의제배당)
⑤ 손금형     = 비용 인정 판정 (0단계 게이트)
```

### §4.3. 5축 → 3축 압축 (형진 발견)

```
[메인] 가산조정 (세금 늘리기)
  A 한도 / B 시점 / C 부당행위 / D 강제 인식

[혜택] 차감조정 (세금 줄이기)
  E 익금불산입 (이중과세, 자본거래, 정책)
  F 손금산입

[보조] 분류 게이트
  G 손금/익금 인정 판정 (옛 ⑤)
```

## §5. 추적 장치 anchor (v4 핵심 신규)

### §5.1. 형진 핵심 명제

> 세법의 작은 규정 하나하나가 자산/권리 추적을 위한 장치

### §5.2. 규정 단위 추적 임무

```
규정                       추적 임무
──────────────────────────────────────────────
비망가액 1,000원           자산 형체/권리 존재
대손 제외 (저당권)         회수 가능성
자산계상 기업업무추진비    자산에 숨은 비용
폐지/철거 기록             자산 행방
결산조정/신고조정 구분     외부 흔적 유무
소득처분 귀속자 분류       돈 받은 사람
유보 누적 (을표)           일시적 차이
사외유출 처분              회사 밖 귀속자
지급의제                   원천징수 회피 차단
원천징수                   개인 소득 즉시 포착
KcLep 시스템              모든 거래 입력 추적
```

= **모든 작은 규정 = 각자 다른 추적 임무**

### §5.3. 추적 비용 최소화 설계

```
귀속자                  추적 방식           원천징수
──────────────────────────────────────────────────────
개인 (주주/임직원/기타) 법인이 즉시 잡기    O
법인/사업자/국가        각자 신고로 잡힘    X

= 개인 = 추적 어려움 → 회사가 대신
= 법인/사업자 = 시스템 추적 가능 → 자력
= 소득세 0.5주차 anchor "행정 낭비 최소화" 직접 작동
```

### §5.4. 추적 안전망 (지급의제)

```
원래 흐름: 법인 → 원천징수 → 개인
회피 시도: 안 줬으니까 원천징수 X

지급의제:
  법인이 원천징수 미루면 의제 시점에 강제 부담
  = 추적 끊기면 법인이 떠안음
```

## §6. 결산조정 vs 신고조정 (v4 신규)

```
결산조정 (회사 안 잡으면 국가도 모름):
  외부 거래 흔적 X
  회사 의사가 출발점
  안 잡으면 차기로 밀림
  → 감가상각, 충당금, 임의 대손, 평가손실
  → 5축 중 ① A1(추정거부) 영역 메인

신고조정 (외부 흔적으로 추적 가능):
  외부 데이터 흐름 있음
  강제 적용
  → 매출 누락, 인건비, 강제 대손, 퇴직연금
  → 5축 중 나머지 거의 전부
```

= **회계 v0.2 발견노트의 증거주의 직접 적용:**
세법 시점 = "외부 검증 가능한 증거가 생긴 시점"

## §7. 비망가액 = 추적 깃발 (v4 신규)

```
비망가액 1,000원 = "비용 인정 + 자산/권리 살아있음" 표식

3 케이스:
  ① 정률법 감가상각 종료 자산
  ② 결산조정 대손 채권
  ③ 자체 판단 파산/부도 주식

공통 원리:
  형체/권리 살아있음 + 회수/처분 가능성 → 깃발 유지
  형체/권리 둘 다 소멸 (강제 대손/멸실/매각) → 깃발 제거
```

= **회계 = 시점 차이 보정 시스템(v0.2)의 사례:**
"비용 시점(완료)" vs "자산 존재 시점(유지)" 분리 표식

## §8. 평가 비대칭 (v4 신규)

```
자산평가증 → 익금불산입 (원칙)
  이유: 회사 추정으로 자산 부풀림 차단

자산평가손 → 손금불산입 (원칙)
  이유: 회사 추정으로 비용 부풀림 차단

= 양방향 추정 거부

예외 (객관 증거 있을 때만):
  평가증: 법률 강제 (보험업법), 외화환산
  평가손: 파산, 천재지변, 재고 파손
```

= **세법 = 추정 거부 원칙 + 객관 증거 예외**

## §9. 4사용자 × 4시점 통합 (v3 + v4 확장)

```
사용자        시점 기준                  증거 종류
──────────────────────────────────────────────────
투자자        발생주의 + 보수 + 실현     회계 추정 OK
              (비용 추정 OK, 수익 추정 NO)

국가-법인세   권리의무 확정주의           법적 확정
              (한도 + 시점 강제)

국가-부가세   증거주의 (공급시기)         외부 검증 가능

국가-소득세   증거 종류별 분기            증거 종류 차이
              사업: 권리의무 확정 (회계 활용)
              근로: 근로 제공일
              이자: 약정일
              배당: 결의일
              연금: 수령일
              기타: 수령일

경영자        의사결정 유용성             내부 자유
              (외부 보고용 + 내부 자유)
```

= **한 거래 = 4개 시점 동시 작동**
= **시점 = 사용자별 신뢰의 함수**

## §10. 한도 base = 재무제표 (v4 신규 검증)

```
법인세 한도 base = 이미 확정된 재무제표 데이터

Stock base (재무상태표):
  대손충당금 ← 채권 잔액
  감가상각 ← 자산 취득가액

Flow base (손익계산서):
  접대비 ← 수입금액
  퇴직급여 ← 총급여
  기부금 ← 기준소득금액

= 회사 사후 조작 불가
= 국가 신뢰 = 데이터 확정성
= "법인세 = 정산 작업" 명제 검증됨
```

KcLep 법인조정 work order = **데이터 의존성 순서**:
```
결산 → 표준재무제표 → 수입금액조정 → 조정후수입금액
→ 감가상각 → 과목별세무조정 → 공제감면 → 자본금적립금
→ 최저한세 → 가산세/원천 → 법인세 과세표준세액조정

= 앞 단계 확정 → 뒤 단계 기준액으로 사용
```

## §11. 영역 간 비교 (v4 갱신)

```
영역          추적 인프라                 핵심 작동

= 사용자 다름 + 추적 방식 다름

## §12. 통합 명제 (v4 최종)

```
회계학 전체 = 데이터 변환 + 사용자별 추적 시스템

각 영역:
  - 메인 사용자 (정해진 신뢰 기준)
  - 변환 메커니즘 (시점 + 분류 + 산식)
  - 추적 인프라 (회피 차단 + 객관성 확보)

법인세 추가 명제:
  - 회계 결과물에 세법 시각 덧씌우기 (출발점 = 재무제표)
  - 작은 규정마다 추적 임무 (비망가액, 결산조정, 사외유출 등)
  - 한도 = 기준액(객관) × 비율(법령) = 추정 거부
  - 평가 = 양방향 추정 거부 + 객관 증거 예외
```
