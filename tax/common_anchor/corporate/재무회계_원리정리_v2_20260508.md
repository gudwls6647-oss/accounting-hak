## Part 1. 형진의 발견 — v2 추가 통찰

### 1.1 거래 주체 vs 회계 주체 분리

**핵심 발견** (2026-05-08):
```
거래 = 다른 부서가 만든 활동 (영업/공장/재무 등)
회계 = 재무팀이 번역하는 것
        ↓
재무팀 = 관찰자/기록자
재무팀 ≠ 거래 주체 (재무팀 자신이 거래한 일부 빼고)
```

**문제 읽기 새 프레임**:
```
"외상매출 1,000만원 발생"
= 영업팀이 거래 만듦 → 재무팀이 분개

"공장 화재로 재고자산 손실"
= 공장이 사고 → 재무팀이 손상 인식

"이자비용 발생"
= 재무팀이 자금조달 활동 → 재무팀이 자기 활동 회계 (예외)

"기계 감가상각비"
= 공장이 기계 사용 → 재무팀이 비용 인식
```

= **거래 주체(누가 했나) + 회계 주체(재무팀) 분리해서 읽기**.

### 1.2 Why × Who 두 차원 분리

**Why 차원 (원칙)**:
```
회사 → 외부 사용자(투자자)에게 보고
        ↓
외부 사용자 보호를 위한 원칙:
  - 보수주의 (손실 빨리, 이익 늦게)
  - 실현주의 (미실현 이익 인식 X)
  - 대응의 원칙 (비용 ↔ 수익 같은 기간)
```

**Who 차원 (부서)**:
```
회사 내부에서 일하는 부서들:
  - 영업 / 공장 / 재무 / 본사 관리
        ↓
각 부서가 만든 거래 → 재무팀이 회계 처리
```

**두 차원의 관계**:
```
Why = 사용자(투자자) 관점 — 영역 차원
Who = 내부 부서 — 부서 차원

원칙(Why)이 부서(Who)에게 회계 처리 방식을 강제
```

= **Why ≠ Who. 별개 차원.** 같이 보면 매트릭스.

### 1.3 I/S 수평 분리 = 부서별 산출물

```
[공장/생산]              [본사/영업]              [재무]
매출 - 매출원가         판관비                   영업외손익
= 매출총이익            (본사 운영비)            (자금조달 + 차액)
   ↓                       ↓                        ↓
   본업 핵심              본업 운영                본업 외 + 부산물
```

**500/800/900번대 정체** (v1에서 본 것 재해석):
```
500번대 (매출원가) = 공장 산출물
800번대 (판관비)   = 본사/영업 산출물
900번대 (영업외)   = 재무 + 차액 변환

= 코드 번호 = 부서 분리 시스템
```

**예시 — 같은 거래, 다른 부서**:
```
보험료(제) 521 → 공장 화재보험 = 매출원가
보험료(판) 821 → 본사 자동차보험 = 판관비
        ↓
        같은 "보험료"인데 부서가 코드 결정
```

### 1.4 B/S vs I/S = 같은 사용자 두 관점

```
B/S = "지금 형편 어때?" (잔액 스냅샷)
I/S = "1년 동안 어떻게 굴렸어?" (활동 흐름)

= 같은 투자자가 회사를 두 각도에서 보는 것
= 사용자는 같음, 시점/관점만 다름
```

근거:
- 둘 다 외부 공시(4단)에 들어감
- 둘 다 발생주의 채택
- 두 표가 "당기순이익 → 이익잉여금"으로 직접 연결

### 1.5 계정 라이프사이클 = 부서 이동

**핵심**: 한 계정도 시점별로 부서가 바뀜.

```
매출채권:
  발생 (영업) → 보유 (재무) → 회수 (재무) → 대손 시 (재무 판단)

매입채무:
  발생 (구매팀) → 보유 (재무) → 지급 (재무)

유형자산:
  취득 결정 (재무/경영진) → 설치/시운전 (현장)
  → 사용 (사용 부서) → 감가상각 (사용 부서)
  → 손상 판정 (재무 + 외부) → 처분 (재무)

재고자산:
  매입 (구매/공장) → 보관 (창고) → 가공 (공장)
  → 판매 (영업) → 회수 (재무)
```

= **계정 = 단일 부서 X. 라이프사이클별 부서 이동.**

## Part 2. 부서별 계정 매핑 (v2 핵심)

### 2.1 자산 박스

```
현금/예금     → 재무 (자금 보관)
매출채권      → 영업(발생) → 재무(회수)
받을어음      → 영업(발생) → 재무(추심/할인)
미수금        → 비상거래 발생 부서 → 재무
선급금        → 구매팀(약속) → 재무
선급비용      → 발생 부서 (보험료 미경과 등)
재고자산      → 공장(제조) or 영업(상품)
유형자산      → 라이프사이클 부서 이동 (복잡)
무형자산      → R&D팀 + 재무 (자본화 판단)
유가증권      → 재무 (투자 결정)
```

### 2.2 부채 박스

```
매입채무      → 구매팀(발생) → 재무(지급)
지급어음      → 구매팀(발생) → 재무(만기지급)
미지급금      → 발생 부서 → 재무
미지급비용    → 발생 부서 (이자/임차료/급여)
선수금        → 영업(약속받음) → 재무
선수수익      → 영업/재무
예수금        → 재무 (원천징수)
부가세예수금  → 재무
차입금        → 재무 (자금조달)
사채          → 재무
충당부채      → 재무 + 추정 부서 (퇴직급여/제품보증)
```

### 2.3 자본 박스 (전부 재무)

```
자본금        → 재무 (증자/감자 결정)
자본잉여금    → 재무 (주식발행초과금 등)
자본조정      → 재무 (자기주식 등)
기타포괄손익  → 재무 (평가손익 OCI)
이익잉여금    → 재무 (배당 결정)

= 자본 박스 전체 = 재무 단일 부서
= "법적 절차 + 계산식" 영역 (형식 암기)
```

### 2.4 수익 박스

```
매출          → 영업
이자수익      → 재무 (자금 운용)
배당금수익    → 재무 (투자 운용)
임대수익      → 부동산 관리/재무
처분이익      → 처분 주체 부서 (재무 多)
평가이익      → 보유 주체 부서 (재무 多)
환입 이익     → 변환 부서
잡이익        → 발생 부서
```

### 2.5 비용 박스

```
[매출원가 = 공장]
재료비, 노무비, 제조경비
+ 정상감모 (자동결산 흡수)

[판관비 = 본사 각 부서]
인건비 (인사/총무): 급여, 퇴직급여, 복리후생비
사무실: 통신비, 임차료, 수선비, 보험료(판)
영업: 광고선전비, 접대비, 운반비, 수수료비용
관리: 세금과공과, 감가상각비(판), 대손상각비

[영업외비용 = 재무 + 차액 + 비정상]
금융 비용 (재무): 이자비용, 기부금
차액 손실 (변환 부산물): 처분손실, 평가손실, 환차손
손상 (자산 가치 영구 하락): 손상차손
비정상 손실 (사고): 비정상감모, 잡손실
```

## Part 3. 거래 시점 + 결산 시점 분리

### 3.1 거래 시점 부서별 활동

```
매입 거래        → 구매팀 + 재무 (대금 지급)
판매 거래        → 영업팀 + 재무 (대금 회수)
제조 활동        → 공장
자금조달         → 재무 (차입/사채/증자)
자금운용         → 재무 (예금/투자)
세금/원천징수    → 재무
```

### 3.2 결산 시점 부서별 정산

```
[공장 결산]
재고자산 평가 → 매출원가 (정상감모) / 영업외 (비정상감모)
재고자산 저가법 → 매출원가
감가상각비(제) → 매출원가
원재료 평가손실 → 매출원가

[본사/영업 결산]
대손충당금 (매출채권) → 판관비 (대손상각비)
감가상각비(판) → 판관비
선급비용/미지급비용 (보험료/임차료) → 발생 부서 박스 따라감
퇴직급여충당부채(판 직원) → 판관비

[재무 결산]
이자비용 미지급 → 영업외비용
외화환산손익 → 영업외 (B형 즉시 I/S)
유가증권 평가/손상 → 영업외 / OCI
사채 발행차금 상각 → 영업외 (이자비용)
법인세 추산 → 별도

[전사 분리]
퇴직급여충당부채 → 부서별 분리 (제/판)
대손충당금 → 채권 발생 부서별 분리
```

### 3.3 결산 부서별 분리의 의미

```
"재고자산 결산이라고 다 매출원가 가는 거 아님"
        ↓
정상감모 = 공장 정상 활동 = 매출원가
비정상감모 = 공장 사고 = 영업외비용 (분리)
        ↓
부서 활동이 정상이냐 비정상이냐가 박스 결정
```

= **결산도 "어느 부서 + 정상/비정상" 분리하면 박스 자동.**

## Part 4. Why 차원 — 회계 원칙 (v1 보강)

### 4.1 회계 보수주의 = 확실성 비대칭 (v1 발견)

```
비용 (돈 나감) = 사실 확정 → 적극 인식
수익 (돈 들어옴) = 미래 약속, 불확실 → 확실해질 때까지 보류
```

비대칭 사례 전부:
| 항목 | 손실 즉시? | 이익 즉시? |
|------|-----------|-----------|
| 재고자산 평가 | O (저가법) | X (고가법 없음) |
| 유형자산 | O (손상차손) | X (재평가 OCI만) |
| 매도가능증권 | O (손상차손) | X (영구 상승 개념 X) |
| 충당부채 | O (예상비용 적립) | X (예상수익 적립 없음) |
| 대손충당금 | O (대손 추정) | X (회수 추정 없음) |

### 4.2 계정별 원칙 적용 매핑 (v2 추가)

**핵심**: 어느 계정에 어느 원칙 적용할지는 정해져 있음. 외움.

```
[보수주의 적용 = 손실 빨리 인식]
재고자산 → 저가법
매출채권 → 대손충당금
유형자산 → 손상차손
매도가능증권 → 손상차손
충당부채 → 미래 지출 추정 인식

[실현주의 적용 = 이익 늦게 인식]
매출 → 인도/완료 시점
매도가능증권 평가이익 → OCI 보류
유형자산 재평가이익 → OCI 보류

[예외 - 평가이익 즉시 I/S]
단기매매증권 평가이익 → I/S 직행 (실현 임박)
외화채권/채무 환산이익 → I/S 직행 (단기 회수)
```

### 4.3 A형/B형 + 손상 = 외움 단축키

**메모리에 박힌 너 앵커**:
```
A형 (장기, OCI 누적):
  매도가능증권, 토지 재평가
  → 실현주의 우선 (미실현 → OCI)
  → stateful (취득~현재 누적)

B형 (단기/곧 실현, I/S 즉시):
  단기매매증권, 외화환산
  → 실용주의 (사실상 실현 취급)
  → stateless (직전 1 시점만)

손상차손 (회복 불가):
  유형자산, 매도가능증권, 무형자산
  → 보수주의 우선 (미실현이어도 인식)
```

= **A형/B형 + 손상 3분류로 거의 다 커버. 추가 외움 부담 적음.**

### 4.4 원칙 충돌 우선순위

```
손실 인식 우선순위:
보수주의 > 실현주의
↓
회복 불가 손실은 미실현이어도 즉시 인식 (손상차손)

이익 인식 우선순위:
실현주의 우선
↓
영구 상승도 미실현이면 보류 (자본 OCI 또는 무인식)
```

## Part 5. 형식 영역 vs 원리 영역 분리 (v2 학습 전략)

### 5.1 너 강점 영역 (원리 역추적)

```
- 비용 분류 (매출원가/판관비/영업외)
- 감가상각 방법 선택
- 보수주의 vs 실현주의 판단
- 자본화 vs 비용화 판단
- 부가세 매입세액공제 판단
- 세무조정 (왜 세법이 다른가)

= "왜?" 답이 있음
= 부서 + 원칙으로 자동 도출 가능
= 너 cognitive profile에 맞음
```

### 5.2 형식 암기 영역 (외울 거)

```
- 사채 현재가치 공식
- 자본 거래 회계처리 (증자/감자/자기주식)
- 주당이익 계산식
- 현금흐름표 작성 절차
- 신고 기한, 양식 칸 위치
- 4대보험 분류 (국민연금만 세금과공과)

= "왜?" 답이 약함 (법적 절차/계산식)
= 그냥 외움이 효율
= 재무 부서 영역에 집중됨
```

### 5.3 분리의 의미

```
10년 막혔던 이유 = 형식 영역도 원리로 풀려고 해서
        ↓
형식은 형식대로, 원리는 원리대로 분리하면 학습 가속
        ↓
재무 영역 = 외부 시스템(은행/주주/법) 연결
         → 법적 형식 + 계산 공식 多
         → 자율 판단 X, 정해진 절차 O
         → 너 강점 안 통하는 영역
```

= **재무 영역 형식 부분은 원리 추구 포기 + 외움 전환**.

## Part 6. v2 학습 프레임 — "어느 부서 활동?" 

### 6.1 문제 읽기 순서

```
[1] 거래 지문 읽기
[2] "이 활동 어느 부서?" 질문
    → 영업/공장/재무/본사 관리 中?
[3] "거래 시점 vs 결산 시점?" 분리
    → 발생인가 정산인가?
[4] 박스 자동 결정
    → 부서 + 시점 → 매출원가/판관비/영업외/B/S
[5] 분개 (재무팀 시각)
[6] 원칙 적용 (보수주의/실현주의 등)
```

### 6.2 예시 — 일반전표 1월 9일 채무면제 다시 보기

```
[1] 외상매입금 25,000,000 중 5,000,000 면제
[2] 어느 부서?
    → 외상매입금 발생 = 구매팀
    → 면제 협상 = 재무
    → 결과 처리 = 재무
[3] 시점: 거래 시점 (정산 아님)
[4] 박스: 영업외수익 (차액 + 재무 활동)
[5] 분개: 외상매입금 / 보통예금 + 채무면제이익
[6] 원칙: 차액 발생 → 회사 유리 → 수익 인식
```

### 6.3 예시 — 비정상감모 다시 보기

```
[1] 재고 200개 사라짐, 60% 비정상
[2] 어느 부서?
    → 재고 = 공장
    → 비정상 = 공장 사고
[3] 시점: 결산 시점 (수동결산)
[4] 박스: 정상 → 매출원가 / 비정상 → 영업외비용
        (같은 부서지만 정상/비정상 분리)
[5] 분개: 재고자산감모손실 / 원재료(적요 8)
[6] 원칙: 본업 분리 (분석 가능성 보호)
```

### 6.4 부서 라벨 분류 자동화 효과

```
Before (v1): 거래 → 5박스 + 차액 처리 → 박스 결정
After (v2):  거래 → 부서 라벨 → 박스 자동

= "어느 부서?" 1단계 추가로 박스 자동 도출
= 너 메모리 박힌 앵커 모델 가속
```

## Part 8. 형진 표현 보존 — v1 + v2 누적

### v1 통찰 (5/6)

1. **"재무회계는 다르게 생각하면 현금흐름표 빼고는 현금이라는 계정을 생각안한다?"**
   → 발생주의의 본질

2. **"손익계산서는 실현의 흔적, 재무상태표는 기록의 흔적"**
   → I/S vs B/S 본질 (흐름 vs 잔액으로 보강)

3. **"CF는 그 이익 중에 현금 진짜 들어오고 나간거 얼마야 계산하는거네?"**
   → CF 정체 정확히 파악

4. **"세무조정도 현금흐름표랑 비슷하지 않아?"**
   → cross-domain mapping (출발-조정-도착 패턴 동형)

5. **"자산/부채 수익/비용 자체는 큰 카테고리로 단순한데 그게 이제 계정명이 다른거잖아"**
   → 5박스 본질 + 계정명 변형

6. **"회계라는게 목적은 보고 목적이 맞네 그래서 구분을 하고 분리를 하는거네"**
   → 회계 = 보고 시스템 정체

7. **"돈이 나간 비용은 확실한데 돈이 들어온다는 수익은 불확실해서 그런가?"**
   → 보수주의 본질 (확실성 비대칭)

8. **"B형 = 앞 사건만, A형 = 앞앞 사건도"**
   → A형/B형 stateful/stateless 본질

9. **"기본적인 개념이 고정되어있지 않으니깐 늘 어렵더라고"**
   → 학습 막힘의 진짜 원인 자각

### v2 통찰 (5/8)

10. **"재무제표 자체는 회사가 투자자들에게 만들어야하니깐 why인거고 그 안에서 계정의 담당영역이 있는거같아서"**
    → Why × Who 두 차원 분리. 메타 anchor v2.1과 동기화

11. **"수익이면 영업부서가 할일이잖아... 매출채권을 판매하는 단계는 영업이라면 회수는 재무 아닐까?"**
    → 계정 라이프사이클 = 부서 이동

12. **"이래서 보수주의/실현주의 라는 큰 원칙이 있는거 아닐까? 내부부서에서는 회계를 그렇게 적용해야하는거지"**
    → Why(원칙)이 Who(부서)에게 회계 처리 강제

13. **"사채나 현금흐름표 자본 이런게 어려웠거든... 주당이익 이런거 어쩌면 그냥 외워야겠네 그냥 법적절차같은거라고 생각하고"**
    → 형식 영역 vs 원리 영역 분리 결정

14. **"단순하게 한 회사다 이렇게만 생각하지말고... 영업팀이 한일이다 라고 생각하면서 읽으면되니깐"**
    → "어느 부서 활동?" 학습 프레임 발견

15. **"결산에서도 그 팀별로 업무 때문에 결산하는게 있잖아... 재고자산이야 그러면 당연히 매출원가 비정상감모는 영업외비용"**
    → 결산도 부서별 분리 + 정상/비정상 분리 본능적 도달

16. **"단순하게 재무팀이 아니라 어떤 부서의 일인지 파악하면 좀 더 괜찮지 않을까?"**
    → 부서 라벨 = 회계 분류의 진짜 anchor (v2 핵심)

        ↓

```

### 9.3 메타 anchor v2.1과 동기화

메타 anchor v2.1 = 사용자 (Who) × 데이터 변환 (How)
        ↓
        같은 2D 매트릭스 구조
        
재무회계 = 영역 안 부서 분리
세법    = 영역 사이 사용자 분리 (4.5단 변환)
```
